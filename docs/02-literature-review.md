# 文献调研：CNKI 与多平台检索

> 状态：规划中，待填充实测内容。

## 目标

用 dsh 完成一次完整的文献调研：从关键词到文献清单，再到可下载 PDF/CAJ。

## 计划内容

- CNKI 高级检索（cnki-advanced-search）：作者 / 标题 / 期刊 / 时间范围 / 来源类别；
- 论文详情提取（cnki-paper-detail）：作者、机构、摘要、关键词、基金；
- PDF/CAJ 下载（cnki-download，需登录态）；
- 期刊收录查询（cnki-journal-index）：北大核心 / CSSCI / SCI / EI；
- 多平台补充调研（agent-reach）：小红书 / B站 / 知乎 / Twitter 看中文与英文讨论。
