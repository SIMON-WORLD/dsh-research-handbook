# 缓存与成本调优

> 状态：规划中。生态实测缓存命中可到 97%（dsh-handbook 数据），本机验证后补全。

## 核心原则

1. **长任务保持会话延续**——别频繁新建会话（缓存命中的前提是 prompt 前缀稳定）；
2. **prompt 前缀稳定**——别老改配置 / 改系统提示词；
3. **看指标**——Web UI 底部「缓存命中 %」。

## 推理档位与成本联动

| 档位 | 成本 | 适用 |
|---|---|---|
| `off` | 最低 | 简单检索、批量脚本 |
| `high` | 中 | 日常默认 |
| `max` | 最高 | 复杂实证分析、长链规划 |

工具链任务 90% 时间在思考——**降档是最快提速手段**。
